# 公开页体验重构设计

## 背景

当前公开页已经能展示赛程、预测入口、历史预测摘要和模型排行榜，但页面气质仍偏工具草稿：

- 首屏标题仍使用“赛程、赔率与 AI 预测对比”，与当前产品定位不一致。
- 赛程卡片在电脑端横向留白过大，核心信息分散，按钮区也显得像临时拼接。
- 真实计分榜是传统表格，字段较多，“近 5 场”的含义不够直观。

这次只处理公开页的信息架构和视觉呈现，不改后端结算规则、不改数据源、不改提示词模板。

## 目标

把公开页调整成“2026 世界杯 AI 预测竞技场”的产品表达：主打多模型预测、模型同场 PK、赛后真实结算。

成功标准：

- 公开首屏不再使用“赔率”作为产品主叙事。
- 赛程卡片在电脑端更紧凑，时间、球队、赛制状态、操作入口在一张卡内形成清晰横向扫描路径。
- 排行榜从复杂表格改成更直观的卡片与分类榜单，用户能一眼看出谁总分最高、谁胜平负更准、谁比分猜得更准。
- 手机端保持可读，不因为电脑端压缩布局导致文字拥挤或按钮错位。

## 范围

本次包含：

- `App` 公开页首屏标题、副标题、说明文字。
- `FixturesPage` 中赛程卡片的 DOM 分组和样式。
- `LeaderboardPage` 中真实计分榜的卡片化和分类切换。
- 相关前端测试更新。

本次不包含：

- 后端积分算法调整。
- 懂球帝数据源扩展。
- API-Football 数据结构调整。
- 提示词模板内容修改。
- 历史预测抽屉的详情报告结构。

## 首屏设计

首屏从“信息展示页”改成“预测竞技场”：

- 顶部小标题使用 `2026 世界杯`。
- 主标题使用 `2026 世界杯 AI 预测竞技场`。
- 支持文案使用 `多模型同场预测，赛后真实结算，用排行榜看谁更懂比赛。`
- 导航仍保留 `赛程`、`排行榜`、`后台`，不引入新的页面。

视觉方向是克制的竞技数据面板：浅底、细边框、深绿色主操作、少量深色标题，不做营销式大幅 hero，也不增加装饰图。

## 赛程卡片设计

电脑端卡片改为四个稳定区域：

1. 时间区：开赛时间、场馆。固定宽度，靠左。
2. 对阵区：两队国旗或徽标、中文队名、英文名。作为视觉主信息，占最大空间。
3. 状态区：轮次、比赛状态、已结束或进行中比分。减少散落文本。
4. 操作区：预测、数据、历史按钮垂直排列；存在反馈时在卡片底部跨列展示预测摘要。

布局原则：

- 缩小卡片高度和无效空白。
- 对阵区与状态区之间不留大片空区。
- 按钮宽度稳定，避免不同文案造成跳动。
- 已结束和进行中比赛优先显示比分。
- 预测反馈继续保留摘要表格和“查看报告”入口，但不抢占未预测卡片的主要空间。

手机端改为纵向卡片：

- 顶部一行展示时间、状态和比分。
- 中部展示对阵。
- 底部展示轮次与操作按钮。
- 预测反馈作为卡片下方内容块。

## 排行榜设计

真实计分榜改为“卡片 + 榜单切换”：

- 顶部三张摘要卡：
  - 综合榜第一名：按 `totalScore` 排名。
  - 胜平负榜第一名：按 `resultHits` 排名。
  - 比分榜第一名：按 `exactScoreHits` 排名。
- 下方使用分段按钮切换榜单：
  - `综合榜`：展示总分、已结算、胜平负命中、比分全中、最近得分。
  - `胜平负榜`：展示胜平负命中、命中率、已结算、总分。
  - `比分榜`：展示比分全中、已结算、总分、最近得分。
- 每一行用紧凑排行卡展示，不再默认使用宽表格。
- `近 5 场` 改名为 `最近得分`，显示最近已结算预测的单场得分序列。

排序规则只在前端展示层使用现有字段：

- 综合榜：`totalScore` 从高到低。
- 胜平负榜：`resultHits` 从高到低，相同则 `resultAccuracy` 高者在前，再相同则 `totalScore` 高者在前。
- 比分榜：`exactScoreHits` 从高到低，相同则 `totalScore` 高者在前。

当没有已结算预测时，继续显示空状态 `暂无已结算预测`，不展示空卡片。

预测活跃榜本次保留现有表格信息，但样式要与新的排行榜面板保持一致，避免上下两个模块视觉割裂。

## 可访问性与响应式

- 分段按钮使用原生 `button`，当前项用 `aria-pressed` 表示。
- 榜单卡片中的排名、模型名、指标值必须是文本，不只依赖颜色。
- 按钮触控高度不低于现有可点击尺寸。
- 长模型名允许换行，不能撑破卡片。
- 桌面宽度下卡片信息要紧凑；手机宽度下不出现横向滚动。

## 测试计划

前端测试更新：

- `App` 测试覆盖新的公开首屏文案。
- `LeaderboardPage` 测试覆盖：
  - 三个榜单切换按钮。
  - 综合榜、胜平负榜、比分榜对应的主要指标。
  - `最近得分` 文案。
  - 空状态。
- `FixturesPage` 测试保留预测入口、数据入口、历史入口和比分展示行为。

手工验证：

- 启动现有 Web 和 API 服务。
- 在电脑端检查首屏标题、赛程卡片空白、排行榜切换。
- 在手机宽度检查赛程卡片和排行榜卡片不会溢出。

## 风险

- 现有排行榜 DTO 字段足够支撑展示，但没有单场明细，因此“最近得分”只能展示分数序列，不能展开到具体比赛。
- 预测反馈摘要表格可能在赛程卡片内占用较多高度；本次只优化默认卡片与摘要入口，不重新设计反馈详情。
- 公开页仍会从 API 定时刷新，布局改造不能影响当前刷新与预测请求流程。
